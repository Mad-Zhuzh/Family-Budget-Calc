# Family Budget Calculator

Небольшой веб-проект для ведения семейного бюджета с поддержкой нескольких валют.

## Возможности

- учет доходов и расходов по категориям;
- пересчет сумм между `RUB`, `USD`, `EUR`;
- блок итогов: доход, расходы, баланс, норма сбережений;
- светлая и темная тема;
- локальное сохранение данных в `localStorage`;
- экспорт и импорт данных в `JSON`;
- мини-лендинг на главной странице с быстрым переходом к калькулятору.

## Запуск

Проект без сборки: откройте файл `calc.html` в браузере.

Альтернатива (рекомендуется для локальной разработки):

1. Запустить простой HTTP-сервер в папке проекта.
2. Открыть страницу по локальному адресу сервера.

## Структура

- `calc.html` — лендинг + калькулятор + стили + скрипты.
